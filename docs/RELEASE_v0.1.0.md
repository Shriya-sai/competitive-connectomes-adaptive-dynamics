# v0.1.0 — Completed computational study

This release records the single-subject Hopf reproduction and its signed-network
null models and perturbation extensions. Across 30 matched simulations the
signed model improved FC fit; sign and weight placement nulls established
dependence on both cooperative and competitive organization; perturbations
separated local susceptibility from remote propagation.

The empirical TMS-fMRI pilot is closed after its frozen participant gate found
no detectable response in the ten motion-QC-passing sites. It supplies no test
of the proposed resting-embedding association.

The release includes a data-free smoke experiment, automated package tests and
correctness lint checks, and a static explorer backed by frozen simulation
results. Large datasets, fitted outputs, licensed software and compiled upstream
binaries must be obtained or generated separately as described in the README.

Interpretation remains bounded to one fitted biological subject. Simulation
seeds are stochastic repetitions; effective negative weights are not identified
with inhibitory synapses.
